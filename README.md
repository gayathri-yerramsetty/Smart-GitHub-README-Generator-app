# Smart-GitHub-README-Generator

## About the Project

Smart GitHub README Generator

## Technologies Used

- Python
- Gradio
- HTML
- CSS
- Markdown

## Features

- User-friendly welcome page, simple project details form, automatic README generation, README preview option, download README as a Markdown file, edit project details option, create multiple README files, attractive user interface.

## Installation

```bash
pip install gradio
```
